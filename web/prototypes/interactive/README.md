# Nexus component library (prototype viewer)

Every interactive component, drawn by Nexus's real panel renderer and painted
cell by cell like a terminal. Nothing here reimplements a widget in HTML.

- `component-sheet.mjs` — one realistic nexus-ui program per component family
  (59 panels, all 72 contracts) plus three small apps. `--export` writes
  `component-sheet.json`.
- `crates/tui/src/interactive/terminal_library_tests.rs` — validates every
  program (normal test run) and, opt-in, exports each one at 76 and 44 columns,
  default and focused, to `component-sheet-frames.json`.
- `terminal-paint.js` — draws exported cells on whole-pixel cells; box, block,
  braille and Powerline round-cap glyphs are drawn as geometry, as terminals do.
- `index.html` / `library.js` / `library.css` — the viewer: all components, or one
  with its focused state, narrow render, contract and source.

Regenerate and view:

```sh
scripts/preview-terminal-panels.sh --export-only
npm --prefix web run prototype:panels   # then open /prototypes/interactive/
```

The preview uses a Tokyo Night palette with round caps on. In Nexus, panels take
your terminal theme; round caps are on in Ghostty, WezTerm, kitty and Omarchy, or
with `NEXUS_ROUND_CAPS=1` (set `0` to force square ends).

The exported frames (`component-sheet-frames.json`, `terminal-frame.*`) are
regenerated by the script and not committed.
